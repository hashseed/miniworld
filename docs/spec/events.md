# Events

The first list of world events, in chronological order, with the title the app shows (in English; every title is localised) and how each appears on the globe (event types are defined in [spec.md](spec.md#5-how-events-appear-in-the-world)). Dates come from general historical knowledge, are approximate where marked "c.", and are checked against sources during the data build.
