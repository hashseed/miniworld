# Epochen

These are the coloured ranges on the timeline, one lane per world region plus a global lane. The Welt lane uses fixed colours per era; regional ranges use the same colour as that polity on the border overlay, so the timeline and the map match. Labels are the German UI labels; English labels are added with the data. Dates are approximate ("um") where historians give a range, and are checked against sources during the data build.
