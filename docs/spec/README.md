# Miniworld specification

This folder is the source of truth for what Miniworld does. Every change to behaviour, content or data format is written here first, then implemented (see [CLAUDE.md](../../CLAUDE.md)).

| File | Contents |
| --- | --- |
| [spec.md](spec.md) | Vision, time model, globe, history data, events, people, interface, localisation, visual style, architecture, content delivery, development environment, milestones |
| [epochen.md](epochen.md) | Era and empire ranges shown as coloured bands on the timeline |
| [ereignisse.md](ereignisse.md) | The first list of world events and how each appears on the globe |
| [persoenlichkeiten.md](persoenlichkeiten.md) | The first list of famous people |

The spec started as a Claude Doc draft written with Yang on 2026-10-17. From now on, changes are made here.
