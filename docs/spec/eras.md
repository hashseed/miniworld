# Eras

These are the coloured ranges on the timeline, one lane per world region plus a global lane. The World lane uses fixed colours per era; regional ranges use the same colour as that polity on the border overlay, so the timeline and the map match. Names here are the English labels; every label is localised like all other UI text. Dates are approximate ("c.") where historians give a range, and are checked against sources during the data build.
