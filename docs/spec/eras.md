# Eras

These are the coloured ranges on the timeline, one lane per world region plus a global lane (spec section 7.1). The World lane uses fixed colours per era; regional ranges use the same colour as that polity on the border overlay, so the timeline and the map match. Every range has an English and a German label. Dates are approximate ("c.") where historians give a range, and are checked against sources during the data build. Ranges in one lane may overlap; overlapping ranges stack into sub-rows.

Every regional lane starts with the peoples who lived there before states and writing, so that no lane is empty in the deep past, which takes a large share of the watching time.
